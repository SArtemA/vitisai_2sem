# Model Card: VitiPredict ML Extended

## 1. Цель моделей
Проект представляет собой пайплайн из двух взаимосвязанных моделей машинного обучения для интеллектуальной оценки земельных участков:
1. **Модель пригодности участка (`BinSuitClassifier`)**: Бинарная классификация географической точки на предмет возможности выращивания винограда.
2. **Модель рекомендации сортов (`MultiGrapeXGBClassifier`)**: Мультиклассовая классификация (ранжирование), формирующая рейтинг подходящих сортов винограда для участка, признанного пригодным.

| Параметр | Описание |
| :--- | :--- |
| **Бизнес-контекст** | Учебный инструмент для комплексной предварительной оценки участков и подбора культур на основе геопространственных данных. |
| **Целевой пользователь** | Студенты, энтузиасты виноградарства, разработчики агротех-проектов. |
| **За пределами scope** | Модели не являются профессиональным агрономическим заключением и не должны использоваться для принятия коммерческих решений без полевой экспертизы. |

## 4. Метрики качества

Оценка качества проводится на отложенной тестовой выборке. Подбор гиперпараметров осуществляется через `GridSearchCV`.

| Метрика | Модель 1 (Пригодность) | Модель 2 (Сорта, macro avg) | Роль в данном проекте |
| :--- | :---: | :---: | :--- |
| **Accuracy** | 0.87 | 0.74 | Общая доля верных предсказаний на тестовой выборке. |
| **Precision** | 0.85 | 0.72 | Минимизация ложных срабатываний (не рекомендовать неподходящий участок/сорт). |
| **Recall** | 0.89 | 0.71 | Минимизация пропусков (найти все потенциально подходящие варианты). |
| **F1-score** | 0.87 | 0.71 | Сбалансированная метрика, критичная при возможном дисбалансе классов сортов. |
| **Confusion Matrix** | Построена | Построена | Визуальный анализ конкретных ошибок классификации. |

**Протокол оценки:**
1. Разделение данных на обучающую и тестовую выборки (train/test split).
2. Масштабирование признаков с помощью `StandardScaler` (fit на train, transform на train и test).
3. Подбор гиперпараметров через кросс-валидацию (`GridSearchCV`).
4. Финальная оценка на тестовой выборке с выводом `classification_report`.

## 5. Ограничения и анализ смещений (Bias / Fairness)

| Фактор / Ограничение | Потенциальный риск | Мера митигации / Примечание |
| :--- | :--- | :--- |
| **Региональная предвзятость** | Если данные собраны по одному региону, модель может ошибаться для других климатических зон. | Явное указание в документации, что модель требует дообучения на локальных данных при смене региона. |
| **Качество входных данных (GEE)** | Ошибки или недоступность Google Earth Engine приводят к fallback-заполнению признаков нулями, что искажает прогноз. | Валидация входных координат и проверка статусов (`_status`) признаков на этапе API-запроса. |
| **Масштабирование (`StandardScaler`)** | Чувствительность к сильным выбросам (outliers) в данных, которые могут исказить среднее и дисперсию при масштабировании. | В будущих версиях рассмотреть `RobustScaler` или дополнительную обработку выбросов перед масштабированием. |
| **Коммерческое использование** | Риск принятия финансовых решений на основе учебной модели. | Наличие дисклеймера в интерфейсе приложения о том, что результат носит исключительно рекомендательный характер. |
