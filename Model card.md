# Model Card: VitiPredict (Оценка пригодности участка для виноградарства)

## 1. Цель модели
Модель предназначена для автоматизированной бинарной классификации географических точек на предмет их пригодности для выращивания винограда. 

| Параметр | Описание |
| :--- | :--- |
| **Бизнес-контекст** | Учебный инструмент для предварительной оценки перспективности земельных участков на основе климатических и геопространственных данных. |
| **Целевой пользователь** | Студенты, энтузиасты виноградарства, разработчики агротех-проектов. |
| **За пределами scope** | Модель не является профессиональным агрономическим заключением и не должна использоваться для принятия коммерческих решений о покупке земли без дополнительной экспертизы. |

## 4. Метрика качества

Оценка качества модели проводится на отложенной тестовой выборке. Для подбора лучших параметров используется `GridSearchCV`.

| Метрика | Описание | Роль в данном проекте |
| :--- | :--- | :--- |
| **Accuracy** | Доля верных предсказаний от общего числа | Общая оценка точности модели на тестовой выборке. |
| **Precision** | Доля истинно положительных среди всех предсказанных положительных | Показывает, насколько мы можем доверять прогнозу "участок подходит" (минимизация ложных срабатываний). |
| **Recall** | Доля истинно положительных среди всех реально положительных | Показывает, насколько хорошо модель находит все подходящие участки (минимизация пропусков). |
| **F1-score** | Гармоническое среднее между Precision и Recall | Сбалансированная метрика, особенно важная при возможном дисбалансе классов. |
| **Confusion Matrix** | Матрица ошибок | Визуальный анализ распределения ошибок (False Positives / False Negatives). |

**Протокол оценки:**
1. Разделение данных на обучающую и тестовую выборки (train/test split).
2. Подбор гиперпараметров через кросс-валидацию (`GridSearchCV`).
3. Финальная оценка на тестовой выборке с выводом `classification_report`.

## 5. Ограничения и анализ смещений (Bias / Fairness)

| Фактор / Ограничение | Потенциальный риск | Мера митигации / Примечание |
| :--- | :--- | :--- |
| **Региональная предвзятость** | Если данные собраны по одному региону, модель может ошибаться для других климатических зон. | Явное указание в документации, что модель требует дообучения на локальных данных при смене региона. |
| **Заполнение пропусков нулями** | Нулевые значения для высоты или осадков физически маловероятны и могут искажать прогноз. | В будущих версиях заменить на медианное заполнение или интерполяцию. Сейчас это задокументированное ограничение. |
| **Статичность признаков** | Модель не учитывает динамические изменения (аномалии погоды текущего года, болезни почвы). | Модель предназначена только для долгосрочной климатической оценки, а не для прогноза на конкретный сезон. |
| **Коммерческое использование** | Риск принятия финансовых решений на основе учебной модели. | Наличие дисклеймера в интерфейсе приложения о том, что результат носит рекомендательный характер. |
